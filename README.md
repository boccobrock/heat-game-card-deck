# Heat Game Card Deck

This is designed to track cards and decks for the board game "Heat - Pedal to the Metal". It has card tracking, deck building, and game state management.

## Installation

To install the dependencies, run:

```bash
npm install
```

## Running the Application

To start the development server, run:

```bash
npm run dev
```

## Features

- Card tracking and management
- Deck building and organization
- Game state persistence
